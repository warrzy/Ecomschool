# Glossaire

| Terme | Définition |
|---|---|
| **ACCRUAL (engagement)** | Mode comptable où la créance produit une écriture D411/C706 dès sa génération, puis D571/C411 à l'encaissement |
| **Année courante** | L'année scolaire active : toutes les listes, inscriptions et finances s'y réfèrent |
| **Avance (sur salaire)** | Somme prêtée à un employé, recouvrée sur les bulletins suivants dans la limite du plafond |
| **Balance âgée** | Ventilation des créances par ancienneté (0-30, 30-60, 60-90, +90 j) |
| **Bulletin** | Relevé périodique des résultats d'un élève ; ou fiche de paie d'un employé selon le contexte |
| **CASH (caisse)** | Mode comptable où seul l'encaissement produit l'écriture |
| **Campagne de paie** | Cycle de calcul des bulletins pour une période donnée |
| **Charge / créance** | Montant dû par un élève généré depuis la grille tarifaire |
| **Coefficient** | Pondération d'une matière dans le calcul des moyennes |
| **Composant de paie** | Rubrique de bulletin (prime, indemnité, retenue) portée par une formule |
| **Contre-passation** | Écriture inverse qui annule une écriture existante — l'écriture d'origine n'est jamais modifiée |
| **Créance** | Synonyme de charge élève |
| **Délibération** | Session du conseil de classe statuant sur les résultats proposés |
| **Dotation de congés** | Attribution automatique de jours selon les règles de l'établissement, à l'activation du contrat |
| **Échéancier** | Ventilation d'une créance en échéances datées |
| **Écriture comptable** | Enregistrement équilibré débit/crédit dans un journal |
| **Exercice** | Période comptable ; sa clôture verrouille les écritures |
| **formulaSnapshot** | Copie figée des formules utilisées dans un bulletin de paie — calcul reproductible |
| **Idempotence** | Propriété qu'une opération rejouée produise le même résultat, sans doublon |
| **isRegulatory** | Verrou d'un composant de paie : tant qu'il est actif, la formule est ignorée — en attente du barème officiel |
| **Mapping comptable** | Correspondance méthode de paiement ↔ compte de trésorerie, catégorie ↔ compte de produit |
| **Membership** | Lien entre un utilisateur, une école et un rôle |
| **OD** | Journal des opérations diverses (écritures non-trésorerie) |
| **Permission** | Droit atomique (`student.read`, `payroll.manage`…) regroupé dans un rôle |
| **Plafond d'avance** | Part maximale du net à payer prélevable par recouvrement mensuel — réglage de l'école |
| **PUBLISHED** | Statut qui rend une évaluation/notes/bulletin visible des familles |
| **Reçu** | Document numéroté `REC-…` émis à l'encaissement, immuable |
| **Report à nouveau** | Écritures d'à-nouveaux reportant les soldes à l'exercice suivant |
| **Rôle** | Ensemble de permissions assigné à un utilisateur dans une école |
| **SYSCOHADA** | Plan comptable des états membres de l'OHADA (utilisé au Burkina Faso) |
| **Tenant** | Établissement scolaire — unité d'isolation des données |
| **UNPAID (congé)** | Congé approuvé sans solde — peut réduire le brut si l'option paie est activée |
