# Démarrage rapide — ECOM-SCHOOL

Ce guide permet à tout nouvel utilisateur d'être opérationnel en 15 minutes.

## 1. Se connecter

Ouvrez l'adresse fournie par votre établissement : **/login**.

![Page de connexion](captures/login.png)

**Étapes :**

1. Saisissez votre **adresse email** (repère 01).
2. Saisissez votre **mot de passe** (repère 02).
3. Cliquez sur **Se connecter** (repère 03).

> [!NOTE]
> Vos identifiants sont communiqués par l'administrateur de votre
> établissement. En cas de mot de passe oublié, utilisez le lien
> « Mot de passe oublié ? » sous le bouton de connexion.

## 2. Retrouver votre espace

Chaque profil arrive dans l'espace qui lui correspond :

| Profil | Espace | Ce que vous y voyez |
|---|---|---|
| Direction / administrateur | `/app` | Tableau de bord, tous les modules autorisés |
| Comptable / caissier | `/app` | Comptabilité, trésorerie, encaissements |
| RH / paie | `/app` | Personnel et/ou paie selon le rôle |
| Enseignant | `/teacher` | Cours, appels, cahier de textes, évaluations |
| Parent | `/parent` | Vos enfants : notes, finances, absences |
| Élève | `/student` | Emploi du temps, notes, bulletins |

![Tableau de bord administrateur](captures/admin-dashboard.png)

## 3. Naviguer dans les menus

Le menu latéral est organisé en **5 sections** : Pilotage, Établissement,
Pédagogie, Finances, Administration. Une entrée n'apparaît que si votre
rôle possède la permission correspondante — une entrée absente est un
cloisonnement normal, pas un bug.

## 4. Premiers réflexes

- **Cherchez les encadrés d'aide** : beaucoup d'écrans affichent une
  notice « Comment fonctionne… ».
- **Une action sensible demande confirmation** : encaissement,
  publication, clôture — lisez avant de valider.
- **En cas de refus 403** : votre rôle n'a pas cette permission ;
  contactez votre administrateur plutôt que le support.

## 5. Checklist de prise en main

- [ ] Je me connecte sans erreur.
- [ ] Je sais quelle section du menu contient mes fonctions.
- [ ] J'ai repéré le bouton **Déconnexion** (en haut à droite).
- [ ] Je sais où trouver les **Notifications**.
- [ ] J'ai identifié l'administrateur de mon établissement.
