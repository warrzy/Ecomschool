# Checklist de prise en main

À cocher lors de vos premières sessions. Chaque ligne renvoie au
manuel correspondant.

## Tout profil

- [ ] Connexion sur l'URL de l'établissement → page de login
- [ ] Premier mot de passe défini via lien d'invitation
- [ ] Menu = uniquement vos permissions (rien de plus, rien de moins)
- [ ] Ouvrir Notifications → « Tout marquer lu » fonctionne
- [ ] Déconnexion propre

## Administrateur — mise en service (ordre obligatoire)

- [ ] Année scolaire créée + périodes + **courante**
- [ ] Niveaux → classes → matières (coefficients) → salles
- [ ] Grille tarifaire (catégories + tarifs)
- [ ] Enseignants + affectations + créneaux EDT
- [ ] Plan comptable démarrage installé + exercice ouvert + mappings
- [ ] Règles de dotation de congés + plafond d'avances + assiduité
- [ ] Utilisateurs créés par rôle + invitations envoyées
- [ ] Un élève test inscrit → créance → paiement → reçu → écriture
- [ ] Une annonce publiée → visible côté portail parent

## Comptable — vérifications quotidiennes

- [ ] Sources non postées → Générer les écritures
- [ ] Balance équilibrée (Σ D = Σ C)
- [ ] Échéances en retard et solde restant (dashboard)
- [ ] Journée de caisse clôturée

## Secrétariat — routine

- [ ] Demandes parents en file → traitement
- [ ] Nouveaux élèves/inscriptions du jour
- [ ] Absences à justifier

## Paie — fin de mois

- [ ] Campagne créée → calculée → vérifiée → validée → **comptabilisée**
- [ ] Avances en cours et plafond vérifiés
- [ ] Rappel : bulletins **indicatifs** tant que les composants
      réglementaires restent verrouillés

## Parent / élève — première visite

- [ ] Sélection du bon enfant (pastille)
- [ ] Emploi du temps consulté
- [ ] Un reçu téléchargé depuis Finances
- [ ] Coordonnées du profil à jour
